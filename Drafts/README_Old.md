
# 📖 النظام التحليلي الشامل للتدبر القرآني

**Comprehensive Analytical System for Quranic Contemplation**

منصة رقمية تفاعلية متقدمة تهدف إلى تيسير تدبر القرآن الكريم، من خلال الجمع بين البحث اللغوي الدقيق، التحليل الموضوعي لمقاصد السور، والاستعراض البصري بالرسم العثماني الأصلي، مع دعم التلاوة الصوتية التلقائية.

---

## ✨ المميزات الرئيسية (Key Features)

* **🔍 محرك بحث ذكي:** بحث متقدم يدعم التطبيع اللغوي للكلمات (توحيد الهمزات والياءات والألف المقصورة) مع القدرة على التقاط الكلمات المستقلة بدقة تامة.
* **📖 استعراض بصري دقيق:** عرض صفحات المصحف الشريف بالرسم العثماني المتجه (SVG) لدقة بصرية لا نهائية.
* **🎧 تلاوة صوتية تلقائية:** دمج مشغل صوتي مخصص (HTML/JS) يقوم بجلب وتشغيل الآيات متتالية تلقائياً بالتزامن مع عرض النص بالرسم العثماني.
* **📊 التحليل الموضوعي والمقاصد:** تصنيف السور والآيات ضمن مجموعات منهجية بناءً على مقاصدها لتسهيل الحفظ والمراجعة.
* **📈 تقارير تفاعلية:** استخراج تقارير إحصائية للكلمات وتكراراتها وتوزيعها على السور والمجموعات.

## 📜 شكر وتقدير (Acknowledgments & Credits)

هذا العمل لم يكن ليرى النور لولا فضل الله أولاً، ثم الجهود العظيمة والمصادر الموثوقة التي استندنا إليها. نتقدم بخالص الشكر والتقدير إلى:

1. **المرجعية العلمية للمقاصد:** تم الاعتماد في استقاء مقاصد السور وتصنيف المجموعات على الجهد العلمي القيم في **"كتاب تسهيل فهم وتدبّر القرآن"** لمؤلفه فضيلة الدكتور/ **عدلي الخطيب**.
2. **المادة الصوتية (API):** تم استخدام واجهة المطورين المفتوحة من مشروع [EveryAyah.com](https://everyayah.com) لجلب التلاوات القرآنية المجزأة (تلاوة الشيخ ماهر المعيقلي).
3. **النصوص القرآنية والرسم العثماني:** مستقاة من قواعد البيانات الموثوقة والمراجعة رقمياً مثل جهود مجمع الملك فهد لطباعة المصحف الشريف وموقع [Tanzil.net](https://tanzil.net).

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **واجهة المستخدم (Frontend):** Python / Streamlit
* **قاعدة البيانات (Backend):** Supabase (PostgreSQL)
* **معالجة البيانات:** Pandas
* **التخصيص والتشغيل:** Custom HTML / CSS / JavaScript
