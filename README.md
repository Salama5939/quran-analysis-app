# 📖 منصة البحث الشاملة ومقاصد القرآن الكريم

تطبيق ويب تحليلي وبحثي تفاعلي مبني باستخدام **Streamlit** وقاعدة بيانات **Supabase (PostgreSQL)**، مصمّم لخدمة الباحثين والمتدبرين في القرآن الكريم عبر استكشاف النص القرآني الكامل، وبناء وتحليل المجموعات الثمانية، ودراسة التناظر بين السور، واستعراض مقاصد السور وموضوعاتها التفصيلية، وتحليل الجذور والآيات المشتركة والمتشابهات بواجهة عربية متكاملة (`RTL`) وتصدير احترافي إلى **Excel**.

## ✨ أبرز المزايا ومعايير العرض

* **اعتماد سحابي كامل على Supabase:** جميع البيانات، العروض التحليلية (`Views`)، والدوال المخزّنة (`RPC`) تُدار وتُسترجع مباشرة من قاعدة بيانات PostgreSQL السحابية دون الاعتماد على ملفات محلية خارجية.

* **هوية بصرية عربية متكاملة (`RTL`):** توحيد اتجاه العرض من اليمين إلى اليسار عبر دالة عرض مستقلة (`prepare_rtl_display_df`) تعكس ترتيب الأعمدة بصرياً للباحث مع الإبقاء على بنية البيانات الأصلية عند التصدير إلى Excel.

* **تنقية البيانات للباحث:** استبعاد الحقول التقنية غير المرغوبة (مثل `created_at` و`id` و`serial_no`) من الجداول المعروضة، وتعريب جميع رؤوس الأعمدة بوضوح.

* **تصدير تقارير Excel احترافية:** إمكانية تصدير كافة الجداول والتقارير المفلترة إلى ملفات `.xlsx` معرّبة ومنسقة بضغطة زر.

## 🗂️ دليل صفحات التطبيق وتبويباتها

### 🏠 `Home.py` — الصفحة الرئيسية

* نقطة الانطلاق للتعريف بالمنصة، عرض الهيكل العام لأقسام التحليل القرآني، والوصول السريع إلى مختلف الصفحات.

### 📖 الصفحة الأولى (`1_📖_المصحف_والبحث.py` / مستكشف المصحف الشريف) — عصب النص القرآني

* تمثّل الركيزة النصية الأساسية للبرنامج لاستعراض النص القرآني الكامل (`full_quran`) والتنقل الدقيق بين السور والآيات والصفحات.

* تتيح البحث المباشر في الآيات الكريمة (بالنص المشكول أو المجرد)، وتصفية النتائج حسب السورة أو نطاق الصفحات مع عرض البيانات المصحفية المرتبطة وتصديرها إلى Excel.

### 🧩 الصفحة الثانية (`2_🧩_المجموعات_والموضوعات.py` / إدارة وتحليل المجموعات الثمانية) — عصب الترابط الموضوعي

* تمثّل المحور الأساسي لربط الآيات بالموضوعات والكلمات المحصورة وتصنيفها ضمن **المجموعات الثمانية** (`ayah_group_relations`).

* تتيح استعراض وتحليل علاقات الآيات داخل كل مجموعة، ومراجعة الكلمات والموضوعات المحصورة، وإدارتها وتصفيتها بدقة مع التصدير المنظّم إلى Excel.

### 🔗 `3_🔗_التناظر_والموضوعات.py` — منصة التناظر وموضوعات السور المتقدمة

تجمع هذه الصفحة بين خريطة التناظر ومقاصد السور وموضوعاتها التفصيلية في **ثلاثة تبويبات متكاملة**:

1. **أولاً: خريطة التناظر والتشابه بين السور والمجموعات:**

   * استعراض سور القرآن الـ 114 من جدول `surah_group_relations` مع التصفية حسب المجموعة والبحث السريع.

   * إظهار **المجموعة المتناظرة** تلقائياً وفق قاعدة التناظر المعتمدة:

     * المجموعة `1` $\leftrightarrow$ المجموعة `5`

     * المجموعة `2` $\leftrightarrow$ المجموعة `6`

     * المجموعة `3` $\leftrightarrow$ المجموعة `7`

     * المجموعة `4` $\leftrightarrow$ المجموعة `8`

2. **ثانياً: مقاصد وموضوعات السور (حسب كتاب التدبر):**

   * استعراض المقاصد العامة للسور من جدول `surah_objectives` مع إمكانية التصفية حسب السورة والتحكم في إظهار الحقول الإضافية وتصدير التقرير.

3. **ثالثاً: موضوعات كل سورة التفصيلية:**

   * استعراض **364 موضوعاً تفصيلياً** تغطي جميع سور القرآن الكريم الـ 114 من جدول `surah_topics_detail` (وفق كتاب *"تسهيل فهم وتدبر القرآن"*).

   * يوفّر فلاتر مترابطة حسب **المجموعة** و**السورة** وبحثاً نصياً داخل تفاصيل الموضوعات، مع مؤشرات سريعة (عدد الموضوعات، عدد السور المشمولة، ومتوسط الموضوعات لكل سورة) وتصدير Excel.

### 🌉 `4_🌉_الربط_الموضوعي.py` — محرك الربط الموضوعي والمقاصدي الذكي

* تحليل شبكة الارتباط للكلمات والموضوعات عبر المجموعات الثمانية باستخدام دالة RPC سحابية (`get_semantic_bridge_card`).

* استعراض توزيع الكلمة المختارة على المجموعات الثمانية ثم استكشاف الآيات والمقاصد التفصيلية التابعة لكل مجموعة تفاعلياً.

### 📈 `5_📈_الخريطة_الإحصائية.py` — الخريطة الإحصائية ولوحة المؤشرات التحليلية

تضم مؤشرات عليا شاملة (KPIs) وتنقسم إلى **تبويبين رئيسيين**:

1. **التبويب الأول: الخريطة الإحصائية والرسوم البيانية:**

   * رسوم بيانية تفاعلية لتوزيع الآيات حسب المجموعات الثمانية وأكثر 10 كلمات تكراراً، مع جدول ملخص إحصائي لكل مجموعة قابل للتصدير.

2. **التبويب الثاني: الاستعراض التفاعلي والبحث الموضوعي العميق:**

   * ينقسم إلى تبويبين فرعيين: **الاستعراض حسب المجموعة**، و**الاستعراض الاستكشافي حسب السورة (بترتيب المصحف)** مع أدوات تصفية متقدمة وتصدير Excel.

### 🔁 `6_🔁_الآيات_المحورية_المكررة.py` — تحليل الآيات المحورية الأكثر ارتباطاً وتكراراً

* استخراج وتحليل الآيات التي تتقاطع فيها عدة موضوعات وكلمات محصورة اعتماداً على العرض السحابي `v_ayah_relations_with_pages`.

* يتيح الترتيب حسب المصحف الشريف أو تنازلياً حسب عدد الموضوعات المرتبطة، مع شريط تمرير لتحديد الحد الأدنى لعدد الموضوعات وتصدير التقرير.

### 🔍 `7_🔍_البحث_العام_الشامل.py` — منصة البحث الشاملة ومقاصد القرآن الكريم

منصة متكاملة من **أربعة تبويبات رئيسية**:

1. **التبويب 1 — إدارة وموضوعات القرآن:** عرض وبحث وتعديل وحذف السجلات الحالية في `quran_topics`، بالإضافة إلى تبويب فرعي لإضافة سجل موضوع جديد مع جلب رقم الصفحة تلقائياً من المصحف.

2. **التبويب 2 — الآيات المتشابهات كلياً:** استكشاف ومقارنة الآيات المتطابقة نصياً بالكامل في المصحف الشريف وتصديرها.

3. **التبويب 3 — المقاطع المشتركة تلقائياً:** استخراج المقاطع المشتركة جزئياً داخل الآيات (`N-grams` من 2 إلى 5 كلمات متتالية) وتصدير مواضع ورودها.

4. **التبويب 4 — الفهرس الهرمي الموضوعي:** بحث هرمي متدرج (الباب الرئيسي $\leftarrow$ الفصل $\leftarrow$ العنوان الرئيسي $\leftarrow$ التصنيف $\leftarrow$ العنوان الفرعي) عبر `v_quran_topics_with_ayahs`.

### 🎯 `8_🎯_أرشيف_الحفظ_والتدبر.py` — أرشيف الحفظ والتدبر الشخصي

* لوحة متابعة وإدارة رحلة الباحث في حفظ وتدبر الآيات الكريمة عبر جدول `user_memorization_archive` مرتبة مصحفياً.

* تعرض مؤشرات الإنجاز (إجمالي الآيات المحفوظة وعدد السور)، وقائمة الآيات المسجلة وحالتها وتاريخ إضافتها، مع أداة لإدارة وحذف السجلات عند الحاجة.

### 📊 `9_📊_الآيات_المشتركة_والموضوعات.py` — محلل ومستكشف الآيات المشتركة والموضوعات المتعددة

تضم لوحة مؤشرات إحصائية لحظية حسب السورة وتنقسم إلى **تبويبين رئيسيين**:

1. **الفهرس الشامل للآيات المشتركة:** عرض كافة الآيات التي وردت في أكثر من موضوع أو كلمة حصر مرتبة مصحفياً مع التصدير إلى Excel.

2. **منصة التدقيق والتحليل المعميق للآية:** اختيار السورة ثم اختيار آية محددة (أو استعراض كافة آيات السورة المشتركة) لمعاينة منطوق الآية وتفاصيل موضوعاتها ومقاصدها ومجموعاتها.

### 🔎 `10_🔍_الاستكشاف_الذكي_للجذور.py` — منصة الاستكشاف الذكي للجذور والمشتقات

تضم **تبويبين رئيسيين**:

1. **التبويب الأول — الاستكشاف الفردي للجذر والحفظ:** البحث في النص القرآني عن جذر أو حروف محددة (مع توحيد رسم الحروف العربية)، واعتماد النتائج وحفظها مباشرة في جدول `smart_root_topics` أو تصديرها.

2. **التبويب الثاني — المرصد المعجمي والحصر الشامل للتقاطعات:** بناء مصفوفة الكلمات المفردة المشتركة مرتبة أبجدياً مع لوحة مؤشرات وتصفية تفصيلية وتصدير مزدوج (التفصيلي والملخص الأبجدي).

## 🗄️ بنية قاعدة البيانات (Supabase)

| الكيان في قاعدة البيانات | النوع | الدور الوظيفي |
| :--- | :--- | :--- |
| `full_quran` | Table | النص القرآني الكامل (المشكول والمجرد) وأرقام السور والآيات والصفحات. |
| `surah_group_relations` | Table | ربط السور الـ 114 بالمجموعات الثمانية وخريطة التناظر. |
| `surah_objectives` | Table | المقاصد العامة لكل سورة من سور القرآن الكريم. |
| `surah_topics_detail` | Table | الموضوعات التفصيلية المرقّمة لكل سورة (364 سجلاً تغطي 114 سورة). |
| `ayah_group_relations` | Table | علاقات الآيات بالكلمات والموضوعات المحصورة والمجموعات الثمانية. |
| `quran_topics` | Table | التصنيف الهرمي للموضوعات القرآنية. |
| `user_memorization_archive` | Table | أرشيف الحفظ والتدبر الشخصي للآيات وحالة الحفظ. |
| `smart_root_topics` | Table | حفظ نتائج الاستكشاف الذكي للجذور والمشتقات. |
| `v_ayah_relations_with_pages` | View | عرض موحّد يجمع ارتباطات الآيات والموضوعات بأرقام الصفحات والمقاصد. |
| `v_quran_topics_with_ayahs` | View | عرض موحّد للفهرس الهرمي الموضوعي مرتبطاً بنصوص الآيات. |
| `get_semantic_bridge_card` | RPC | دالة تحليل شبكة الارتباط الدلالي والمقاصدي عبر المجموعات الثمانية. |

## ⚙️ المتطلبات والتشغيل المحلي

### 1. استنساخ المستودع وتثبيت الاعتماديات

```bash
git clone <رابط-المستودع-على-GitHub>
cd <مجلد-المشروع>
pip install -r requirements.txt
```

### 2. إعداد مفاتيح الاتصال بـ Supabase

أنشئ ملف `.env` في المجلد الرئيسي للمشروع (أو أضف المفاتيح في `.streamlit/secrets.toml`):

```env
SUPABASE_URL="https://your-project-id.supabase.co"
SUPABASE_KEY="your-supabase-anon-or-service-key"
```

### 3. تشغيل التطبيق

```bash
streamlit run Home.py
```

## 🛠️ التقنيات المستخدمة

* **Python 3.10+**
* **Streamlit** (بناء الواجهات التفاعلية ولوحات المؤشرات)
* **Supabase Python Client** (الاتصال السحابي بقاعدة بيانات PostgreSQL واستدعاء Views وRPC)
* **Pandas & OpenPyXL** (معالجة البيانات التحليلية وتصدير تقارير Excel)
* **Plotly Express** (الرسوم البيانية التفاعلية)
