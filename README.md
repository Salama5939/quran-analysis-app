# 📖 النظام التحليلي الشامل لتدبر القرآن العظيم والبحث الذكي

منصة رقمية أكاديمية وتفاعلية مبنية باستخدام **Python** و**Streamlit** وقاعدة بيانات **Supabase (PostgreSQL)**، مصمّمة لخدمة الباحثين والمتدبرين والحفّاظ عبر الجمع بين التلاوة البصرية والصوتية، والتحليل المفاهيمي والهرمي، واستكشاف المتشابهات والجذور القرآنية بهوية بصرية عربية موحدة (`RTL`) وبطاقات آيات عثمانية وتصدير احترافي إلى **Excel**.

---

## ✨ أبرز المزايا الهندسية والوظيفية

* **هوية بصرية موحدة وبطاقات آيات عثمانية:** تصميم عربي متكامل من اليمين إلى اليسار (`RTL`) يعتمد البطاقات التدبرية المزخرفة بالرسم العثماني والشارات التفاعلية بدلاً من الجداول الجامدة.
* **مصحف مزدوج عالي الدقة (604 صفحة):** التصفح الفوري بين **مصحف التجويد الملون** ومصحف **المدينة العثماني الكلاسيكي** مع دليل ألوان أحكام التجويد وأزرار تقليب متزامنة.
* **تلاوة صوتية ذكية للقراء الثلاثة:** دعم التلاوة عالية الجودة (`128kbps` عبر EveryAyah) بصوت **الشيخ ماهر المعيقلي**، و**الشيخ سعود الشريم**، و**الشيخ محمود خليل الحصري**، سواء لتكرار الآيات المختارة للحفظ أو لتلاوة الصفحة كاملة.
* **اعتماد سحابي كامل على Supabase:** إدارة واسترجاع كافة البيانات والعروض التحليلية (`Views`) والدوال المخزّنة (`RPC`) مباشرة من قاعدة بيانات PostgreSQL السحابية دون قيود الحد الأقصى للصفوف.
* **دليل إرشادي مدمج وملف PDF شامل:** بطاقة إرشادية تفاعلية قابلة للطي داخل كل بوابة تشرح تبويباتها وطريقة استخدامها، بالإضافة إلى دليل المتدبر الشامل (`PDF`) القابل للتحميل من الواجهة الرئيسية.
* **تصدير تقارير Excel احترافية:** إمكانية تصدير كافة النتائج والفهارس المفلترة إلى ملفات `.xlsx` معرّبة ومنسقة بضغطة زر.

## 🗂️ هيكل البوابات التفاعلية الثمانية (`pages/`)

### 🏠 `Home.py` — الواجهة الرئيسية ولوحة الانطلاق

* تعرض مؤشرات الإحصاء الحية للمنصة من قاعدة البيانات، وزر تحميل **دليل المتدبر الشامل (`PDF`)**، وبطاقات الانتقال السريع إلى البوابات الثمانية.

### 1️⃣ `1_📖_المصحف_المصور.py` — المصحف المصور والتلاوة الذكية والحفظ

* **التبويب الأول (المصحف المصور التفاعلي):** عرض الصفحتين المتقابلتين (من الغلاف `-1` والبسملة `0` وصفحات `1–604`) مع التبديل الفوري بين مصحف التجويد الملون والمصحف العثماني، وخيار الاستماع لتلاوة الصفحة كاملة.
* **التبويب الثاني (التلاوة الذكية للآيات والتدبر والحفظ):** استعراض الآيات ببطاقات عثمانية مقترنة بمقصد السورة وحالة الحفظ، مع مشغل تلاوة متسلسل للتكرار (1–10 مرات) وحفظ الآيات أو تسجيل مراجعتها في `user_memorization_archive`.

### 2️⃣ `2_🧭_المعمارية_المفاهيمية.py` — المعمارية البصرية والمفاهيمية

* استعراض الخريطة البنيوية الشاملة للطبقات الخمس والمحاور الـ 24 والعقد المعرفية الـ 96 المرتكزة على قاعدة **نفي الترادف القرآني**.

### 3️⃣ `3_🏛️_معمارية_المجموعات_الثمانية.py` — معمارية المجموعات الثمانية

* الخريطة الهرمية الشاملة للمجموعات الثمانية وسور القرآن الكريم الـ 114 ومقاصدها العامة وبنائها المقطعي وعلاقات التناظر بين المجموعات المتقابلة (`1↔5`, `2↔6`, `3↔7`, `4↔8`).

### 4️⃣ `4_📊_الإحصاءات_والرسوم_البيانية.py` — الإحصاءات والرسوم البيانية

* لوحة مؤشرات تحليلية (`KPIs`) ورسوم بيانية تفاعلية توضّح توزيع الآيات والمفاهيم المحصورة عبر المجموعات الثمانية والسور، مع أدوات التصفية وإدارة الحصر والتصدير إلى Excel.

### 5️⃣ `5_🔗_الآيات_المحورية_والمتشابهات.py` — الآيات المحورية والمتشابهات

1. **الآيات المحورية الكبرى:** استعراض الآيات الجامعة لأكبر عدد من المفاهيم المحصورة.
2. **تقاطع مفهومين داخل الآية الواحدة:** استخراج الآيات التي تجمع بين مفهومين محددين.
3. **الفهرس الإحصائي الشامل:** كشف تحليلي قابل للفرز والتصدير إلى Excel.
4. **المتشابه اللفظي في المصحف الشامل (`full_quran`):** مقارنة أي آية أو سورة كاملة مع نظائرها في المصحف الـ 6,236 مع تظليل مواضع الاتفاق باللبني والفروق اللفظية بالذهبي، واستخراج العبارات المتكررة (`N-Grams`).

### 6️⃣ `6_🗂️_الفهرس_الهرمي_الموضوعي.py` — الفهرس الهرمي الموضوعي

1. **المستعرض الهرمي التفاعلي:** تصفية متدرجة من 5 مستويات (`الباب الرئيسي` ⬅ `الفصل` ⬅ `العنوان الرئيسي` ⬅ `التصنيف` ⬅ `العنوان الفرعي`) مع بحث نصي شامل وبطاقات آيات عثمانية.
2. **إضافة سجل موضوعي جديد:** إدراج تصنيفات جديدة في `quran_topics` مع معاينة فورية للآية ورقم صفحتها.
3. **تعديل أو حذف السجلات الحالية:** تحرير مباشر وآمن لقاعدة البيانات.

### 7️⃣ `7_🔎_الاستكشاف_الذكي_للجذور.py` — الاستكشاف الذكي للجذور والمشتقات

1. **الاستكشاف الفردي للجذر والمشتقات:** استخراج جميع مشتقات الجذر وتلوينها داخل الآية العثمانية، وحفظها مباشرة في جدول `smart_root_topics`.
2. **أرشيف الجذور المعتمدة:** استعراض وإدارة الجذور المحفوظة وتصديرها أو حذفها.
3. **المرصد المعجمي التفاعلي:** فهرس أبجدي شامل للمفردات المشتركة في المصحف يتيح النقر المباشر على أي كلمة لعرض آياتها مظللة فوراً.

### 8️⃣ `8_🎯_أرشيف_الحفظ_والتدبر.py` — أرشيف الحفظ والتدبر الشخصي

* لوحة متابعة وإدارة رحلة الحفظ والمراجعة الدورية للآيات الكريمة عبر جدول `user_memorization_archive` مرتبة مصحفياً.

## 🗄️ بنية قاعدة البيانات (Supabase PostgreSQL)

| الكيان في قاعدة البيانات | النوع | الدور الوظيفي |
| :-------------------------------------------- | :--------- | :---------------------------------------------------------------------------------------------------------------------------- |
| `full_quran` | Table | النص القرآني الكامل (المشكول والمجرد) وأرقام السور والآيات والصفحات. |
| `surah_pages` | Table | فهرس السور الـ 114 وأرقام صفحات البداية والنهاية. |
| `surah_group_relations` | Table | ربط السور الـ 114 بالمجموعات الثمانية وخريطة التناظر. |
| `surah_objectives` | Table | المقاصد العامة لكل سورة من سور القرآن الكريم. |
| `surah_topics_detail` | Table | الموضوعات التفصيلية المرقّمة لكل سورة (364 سجلاً تغطي 114 سورة). |
| `ayah_group_relations` | Table | علاقات الآيات بالكلمات والموضوعات المحصورة والمجموعات الثمانية. |
| `quran_topics` | Table | التصنيف الهرمي ذو المستويات الخمسة للموضوعات القرآنية. |
| `user_memorization_archive` | Table | أرشيف الحفظ الشخصي للآيات وعدادات المراجعة وتواريخها. |
| `smart_root_topics` | Table | أرشيف نتائج الاستكشاف الذكي للجذور والمشتقات. |
| `v_ayah_relations_with_pages` | View | عرض موحّد يجمع ارتباطات الآيات والموضوعات بأرقام الصفحات والمقاصد. |
| `v_quran_topics_with_ayahs` | View | عرض موحّد للفهرس الهرمي الموضوعي مرتبطاً بنصوص الآيات. |
| `get_semantic_bridge_card` | RPC | دالة تحليل شبكة الارتباط الدلالي والمقاصدي عبر المجموعات الثمانية. |

## ⚙️ البيئة التقنية ومتطلبات التشغيل

تعتمد المنصة على حزمة متكاملة من التقنيات السحابية والبرمجية الحديثة، ويمكن تشغيلها محلياً أو نشرها سحابياً عبر الخطوات المتسلسلة التالية:

### 1. التقنيات والاعتماديات الأساسية

* **لغة البرمجة وواجهة المستخدم:** `Python 3.10+` مع إطار العمل التفاعلي **`Streamlit`** لبناء البوابات الثمانية والعارض المزدوج للمصحف (`Flipbook`).
* **قاعدة البيانات السحابية:** **`Supabase (PostgreSQL)`** عبر مكتبة `supabase-py` لإدارة الجداول، العروض التحليلية (`Views`)، والدوال المخزّنة (`RPC`).
* **المعالجة التحليلية والتصدير:** مكتبتا **`Pandas`** و**`OpenPyXL`** لتنقية البيانات وبناء تقارير `Excel` معرّبة ومنسقة.
* **الرسوم البيانية التفاعلية:** مكتبة **`Plotly Express`** لعرض المؤشرات والتوزيعات الإحصائية.
* **الوسائط القرآنية:** 604 صفحة عالية الدقة لمصحف التجويد الملون والمصحف العثماني (`PNG`)، وتلاوات صوتية (`128kbps MP3`) عبر شبكة `EveryAyah` للقراء الثلاثة.
